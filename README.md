# Dead of Night

Зомби-хоррор от первого лица в заброшенной школе «Рассвет».

**Играть:** https://fgfjnker-collab.github.io/dead-of-night/

Управление: WASD — ходьба, Shift — бег, ЛКМ — стрельба, ПКМ — прицел, R — перезарядка, F — купить / открыть / заколотить окно, V — нож, G — граната, 1/2/колесо — оружие, Esc — пауза.
